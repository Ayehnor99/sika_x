# sika_x

Ghana-first personal AI agent (Pidgin + English + simple Twi).

## Quickstart (5 lines)

    git clone <your-repo-url> && cd sika_x
    uv sync
    cp .env.example .env
    uv run ruff check .
    uv run pytest
